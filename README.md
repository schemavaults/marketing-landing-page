# @schemavaults/marketing-landing-page

This is the code for [the landing page for SchemaVaults](https://schemavaults.com).

## Development

```bash
# first install dependencies with `bun install`
bun run dev
```

## Production Build

```bash
# first, install dependencies with `bun install`
# second, ensure that the variables at .env.example are set in your local .env.local (or equivalent)
bun run build
```
